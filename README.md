# Kütüphane

Kitap ve üye ekleyip çıkarabileceğiniz, ödünç ve iade alabileceğiniz küçük bir kütüphane uygulaması. Ana sayfa kimin hangi kitabı aldığını gösterir.

## Çalıştırma

```
pip install -r requirements.txt
python run.py
```

Tarayıcıda açın: http://127.0.0.1:5000

## Sayfalar

- `/` — kitaplar ve ödünç listesi
- `/members` — üyeler
- `/add_book` — kitap ekle
- `/add_member` — üye ekle
- `/borrow` — ödünç
- `/return` — iade
